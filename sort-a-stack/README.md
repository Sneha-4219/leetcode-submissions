<h2>Sort a Stack</h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Given a stack of integers <code>st[]</code>. Sort the stack in ascending order (smallest element at the bottom and largest element at the top).</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input</strong>
st[] = [41, 3, 32, 2, 11]

<strong>Output</strong>
[41, 32, 11, 3, 2]

<strong>Explanation</strong>
After sorting, the smallest element (2) is at the bottom and the largest element (41) is at the top.
</pre>

<p>&nbsp;</p>
<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input</strong>
st[] = [3, 2, 1]

<strong>Output</strong>
[3, 2, 1]

<strong>Explanation</strong>
The stack is already sorted in ascending order.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li>1 &le; st.size()</li>
	<li>1 &le; st[i] &le; 10<sup>3</sup></li>
</ul>
