# DSA-LeetCode

A collection of my **Data Structures & Algorithms (DSA)** practice and **LeetCode solutions in C++**, organized around common problem-solving patterns.

The goal of this repository is to build strong problem-solving skills by understanding **patterns, approaches, edge cases, and complexity** rather than solving problems randomly.

---

## 🧠 Learning Approach

I am following a **pattern-based approach** to DSA.

For each pattern, I focus on:

* Understanding the core concept
* Identifying when the pattern can be applied
* Solving representative LeetCode problems
* Understanding different approaches
* Analyzing time and space complexity
* Revisiting problems for revision

---

## 📚 Patterns Covered

### 1. Arrays & Hashing

Problems involving arrays, frequency counting, hash maps, sets, and related techniques.

### 2. Two Pointers

Using two pointers to efficiently process arrays and strings.

### 3. Binary Search

Problems involving sorted arrays and binary search on the search space.

### 4. Sliding Window

Maintaining a dynamic or fixed-size window to solve subarray/substring problems efficiently.

### 5. Stack

Problems involving LIFO processing, monotonic stacks, expression evaluation, and related techniques.

### 6. Linked List

Coming next — focusing on traversal, pointer manipulation, reversal, fast & slow pointers, and common linked-list patterns.
